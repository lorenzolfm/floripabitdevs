Paradigma para verificar computações arbitrárias no Bitcoin sem soft fork: o resultado é afirmado off-chain e só é contestado on-chain, por meio de provas de fraude, se estiver errado. É usado para construir pontes com confiança mínima para rollups e sidechains; versões mais novas usam circuitos garbled para baratear a verificação.
