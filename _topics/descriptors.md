Output script descriptors são uma linguagem para descrever quais scripts — e portanto quais endereços — uma carteira controla, incluindo chaves, caminhos de derivação e tipo de saída. Facilitam backups e a interoperabilidade entre carteiras. São especificados a partir do BIP380.
